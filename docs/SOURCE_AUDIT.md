# Project Audit Report: Chest X-ray Intelligence Studio

## Executive Summary
This document provides the formal engineering and medical AI audit of the codebase prior to the Phase 2-5 upgrade. Every component—from frontend dropdown rendering to deep learning architecture math, explainability hooks, and GraphRAG retrieval—was examined against the project requirements and reference training notebooks (`DenseNET121.ipynb`, `implementation_capsnet.ipynb`, and `CAPSTONE_VIT_CHEXPERT_CLEAN.ipynb`).

---

## Complete Audit Matrix

| Area | Current Condition | Identified Problem | Required Correction | Severity Level |
|---|---|---|---|---|
| **Frontend Model Selector** | `frontend/app.js` populated `<select id="model-select">` with `<option ... disabled>` when `m.available` was False, and `models.find(m => m.available)` evaluated to `undefined`. | Model dropdown was completely blank and unselectable when weights were not yet installed. Users could not explore architectures or view status. | Always render all 4 models (ViT-B/16, DenseNet121, CapsNet, GAT) with status badges (`Available`, `Missing Checkpoint`, `Loading`). Allow user selection regardless of weights; display clear training commands and disable inference button cleanly without mock outputs. | **Critical** |
| **Frontend Layout & Workflow** | 4 tabs (`analysis`, `comparison`, `explain`, `about`) with single-image `<input>` element and 2-panel overlay display. | Lacks required 5-tab structure; missing 1–5 multi-image drag-and-drop batch upload; missing OOD rejection modal; missing finding-specific XAI dropdown. | Redesign into 5 medical dark-mode tabs: 1. Image Analysis (1–5 batch upload, thumbnail carousel, OOD alerts), 2. Explainable AI (4-panel grid), 3. GraphRAG Evidence, 4. Model Benchmark, 5. About Project. | **High** |
| **ViT Architecture** | `backend/models.py` initialized TorchVision `vit_b_16(weights=weights)`. | TorchVision ViT cannot load Hugging Face checkpoint weights from `CAPSTONE_VIT_CHEXPERT_CLEAN.ipynb` (`google/vit-base-patch16-224`); lacks layer-by-layer attention tensor extraction for Attention Rollout. | Implement Hugging Face ViT-B/16 (`google/vit-base-patch16-224`) with `AutoImageProcessor`, 13-label classification head, multi-layer self-attention rollout over all 12 layers, and patch embedding gradient hooks. | **Critical** |
| **DenseNet121 Architecture** | `backend/models.py` had basic DenseNet121 with naive Grad-CAM. | Inflexible checkpoint path resolution failed on notebook checkpoint `best_densenet121_chexpert.pth`; lacked multi-label class-specific CAM targeting. | Support notebook checkpoint names, multi-label BCE loss with positive weighting, and class-specific Grad-CAM targeting `features.denseblock4`. | **High** |
| **Capsule Network (CapsNet)** | `backend/models.py` forward pass returned a single logit tensor. Explainability used 1st-order Grad-CAM. | Forward pass broke dictionary interface (`probabilities`, `capsules`) used in `implementation_capsnet.ipynb`. Explainability lacked true Grad-CAM++ higher-order gradients. | Re-align CapsNet to notebook architecture: Conv1-3 + 784 Primary Capsules (dim 8) + 13 Disease Capsules (dim 16) + dynamic routing; implement true Grad-CAM++ with 1st, 2nd, and 3rd order gradients on Conv3. | **Critical** |
| **Graph Attention Network (GAT)** | Tightly coupled inside `models.py` with simplistic attention averaging. | Lacks modular definition in `gat.py`; lacks 8-neighbor spatial adjacency graph formulation; lacks clear node/edge attribution. | Create `backend/gat.py` implementing ResNet spatial patch extractor (7×7 grid = 49 nodes), 8-neighbor spatial adjacency matrix with self-loops, multi-head GAT layers, and region attention maps. | **High** |
| **Out-of-Distribution (OOD) Detector** | Non-existent; arbitrary inputs (cars, dogs, food, brain MRI) were directly fed into the CNN/Transformer. | Non-medical images produced nonsensical pathology scores instead of being properly rejected. | Implement `backend/ood_detector.py` combining color saturation checking, bimodal thoracic histogram analysis, texture entropy, and cross-modality geometry to reject non-CXR inputs before inference. | **Critical** |
| **Explainable AI (XAI)** | Single fused image overlay in `backend/explain.py`. | Failed to provide the required **4-panel grid**: Panel 1 (Original), Panel 2 (Model Heatmap), Panel 3 (ViT Attention Rollout / Secondary View), Panel 4 (Fused Overlay). | Create `backend/explainability.py` and `backend/visualization.py` generating the full 4-panel visual explanation suite with finding-specific attribution selector. | **High** |
| **GraphRAG & Evidence Engine** | `backend/graph_rag.py` was a stub; `docs/medical_evidence.json` was empty `[]`. | Zero verified citations; no granular anatomical mappings; no strict clinical grounding prompt. | Implement granular Biomedical Knowledge Graph in NetworkX linking all 13 findings to anatomical regions, categories, and verified NCBI Bookshelf/PubMed citations; enforce strict grounding prompt rules. | **Critical** |
| **Colab Training Notebook** | `docs/CheXpert_Capstone_Training_Colab.ipynb` assumed `/content/chexpert_capstone`. | Failed when Google Colab extracted the project ZIP into a different folder name (`/content/Chest_Xray_Intelligence_Studio`). | Create `notebooks/CheXpert_Colab_Training.ipynb` featuring self-healing root discovery that searches for `backend/train.py` regardless of folder naming, with automated cells for all 4 models. | **High** |
| **Benchmarking & Validation** | `backend/metrics.py` computed raw metrics; `benchmark_results.json` was missing; UI table was blank. | Historical empirical metrics from reference notebooks were not preserved; comparison charts were absent. | Implement `backend/benchmark.py`, populate `benchmark_results.json` with empirical metrics (DenseNet AUROC 0.7183, CapsNet AUROC 0.6786, ViT F1 0.84), and render dynamic comparison charts in UI. | **High** |
| **Testing & Quality Assurance** | Only basic `test_smoke.py` existed. | Incomplete automated coverage; no tests for OOD, architectures, GraphRAG, or batch inference. | Create comprehensive test suite in `tests/` covering architectures, OOD detection, explainability, GraphRAG, batch inference, training, and API routing. | **Medium** |
