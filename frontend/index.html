Vision Transformer (ViT-B/16)

PRIMARY RESEARCH MODEL
Calibrated Threshold: 0.40

Patch self-attention creates diffuse logit distributions; 0.40 delivers optimal F1 (0.584) and 89.2% sensitivity without inflating false positives.

Optimism Bias & Mitigation:

Every patch interacts directly with all 195 other patches. Diffuse thoracic contrast can artificially boost multi-label logits simultaneously. Mitigation: Anatomical lung field masking prunes non-thoracic tokens, and calibrated threshold (0.40) prevents diffuse over-calling.

Hidden Dependencies:

ViT naturally models bilateral disease spread (consolidation + effusion in congestive heart failure). However, external high-density items (pacemaker leads, clips) can falsely correlate with parenchymal consolidation if unmasked.

Operational Scope:

In-Scope: Multifocal pneumonia, bilateral edema, COVID-19/ARDS, hemithorax asymmetry. Out-of-Scope: Fine linear hairline rib fractures (<1mm) and micro-apical pneumothorax lines.

How to Test: Select ViT-B/16, set threshold to 0.40, and upload/paste CXR. Check Panel 1 for focal bounding boxes and Panel 4 for fused overlay.

DenseNet-121

ESTABLISHED CNN BASELINE
Calibrated Threshold: 0.45

Dense feature reuse produces concentrated feature representations; 0.45 threshold balances sharp precision (0.548) with high recall.

Optimism Bias & Mitigation:

Concentrated gradient accumulation across dense blocks causes high-contrast anatomical borders (ribs, diaphragm) to generate overconfident activations. Mitigation: Batch-norm feature stabilization and denseblock4 Grad-CAM spatial averaging.

Hidden Dependencies:

Sensitive to patient rotation and AP vs PA projection geometry. Patient rotation shifting mediastinum into the left hemithorax can falsely trigger Cardiomegaly. Mitigation: Anatomical cardiac contour masking.

Operational Scope:

In-Scope: Dense lobar consolidations with air bronchograms, circumscribed nodules, and pleural effusion fluid menisci. Out-of-Scope: Cross-hemithorax holistic relational reasoning.

How to Test: Select DenseNet-121, set threshold to 0.45, and inspect dense lobar air bronchograms in Panel 3.

Capsule Network (CapsNet)

SPATIAL POSE & ROUTING
Calibrated Threshold: 0.40

Vector capsule lengths ||v_j|| bounded in [0, 1] require a 0.40 decision boundary for multi-label agreement.

Optimism Bias & Mitigation:

Routing agreement can cause capsule length to saturate near 1.0 on large geometric shapes (e.g. cardiac shadow). Mitigation: 3-iteration dynamic routing with margin loss bounds and 3rd-order Grad-CAM++.

Hidden Dependencies:

Strongly couples disease detection to geometric pose and affine transformation parameters. Under-detects amorphous diffuse ground-glass infiltrates lacking distinct boundaries.

Operational Scope:

In-Scope: Structural, geometric findings: Cardiomegaly (CTR > 0.50), Enlarged Cardiomediastinum, Pleural Effusion meniscus contouring. Out-of-Scope: Diffuse interstitial reticular markings.

How to Test: Select CapsNet, set threshold to 0.40, and verify cardiac silhouette boundary in Panel 2 & 4.

Graph Attention Network (GAT)

7×7 SPATIAL TOPOLOGY
Calibrated Threshold: 0.38

Graph message passing across 49 nodes diffuses logits; 0.38 provides optimal detection for inter-regional spread.

Optimism Bias & Mitigation:

Graph edge attention over-smoothing can diffuse focal lesion activations across adjacent lung zones. Mitigation: Localized 8-connectivity edge attention entropy normalization.

Hidden Dependencies:

Models anatomical disease spread pathways (lobar pneumonia spreading to adjacent segments). External leads spanning nodes can simulate false disease propagation edges without anatomical masking.

Operational Scope:

In-Scope: Inter-regional disease spread, multi-lobar tracking, lobar fissure boundary verification. Out-of-Scope: Small solitary pulmonary nodules (<10mm) constrained by 32×32 pixel nodes.

How to Test: Select GAT, set threshold to 0.38, and observe regional 7×7 node attention in Panel 3.

Architectural Trade-offs & Genuine Model Strengths

Scientifically Grounded Evaluation

ViT-B/16 (Primary Model) Macro AUROC: 0.8284

Primary Research Architecture: Excels in long-range contextual spatial reasoning across bilateral hemithoraces. Demonstrates highest performance on diffuse airspace opacities (Consolidation: 0.7910, Pneumonia: 0.7650, Lung Opacity: 0.8850) and foreign bodies (Support Devices: 0.9230).

DenseNet121 (CNN Baseline) Macro AUROC: 0.8122

Local Gradient Precision: Dense feature concatenation preserves fine edge gradients. Genuinely outperforms ViT on Cardiomegaly (0.8520 vs 0.8410) due to precise cardiothoracic ratio boundary detection, and on Fracture (0.7540 vs 0.7420) via high-frequency cortical line filters (~18ms latency).

Graph Attention Network (GAT) Macro AUROC: 0.7964

Spatial Relational Reasoning: 49-node image-region graph with 8-neighbor spatial adjacency. Genuinely outperforms ViT on Pleural Effusion (0.9180 vs 0.9120) and Edema (0.8690 vs 0.8620) by modeling bilateral dependent fluid dynamics between costophrenic angles and perihilar zones.

Capsule Network (CapsNet) Macro AUROC: 0.7782

Part-Whole Geometric Equivariance: 784 primary capsules dynamically routed into 13 disease vector capsules. Genuinely outperforms ViT on Enlarged Cardiomediastinum (0.7150 vs 0.6820) due to intrinsic equivariance under patient rotation and thoracic posture variation.

PRIMARY PROPOSED

Vision Transformer (ViT-B/16)

Hugging Face Transformer fine-tuned on 13 CheXpert findings. Processes 196 non-overlapping 16×16 patches across 12 transformer encoder blocks. Provides recursive Attention Rollout across all 12 multi-head layers and class-specific Gradient × Activation attribution on patch embeddings.

CNN BASELINE

DenseNet121

Densely connected convolutional network enforcing feature reuse and strong gradient propagation across dense blocks. Features a 13-label linear classification head with class-specific Grad-CAM heatmaps generated from features.denseblock4.

PART-WHOLE MODEL

Capsule Network (CapsNet)

Preserves hierarchical part-whole relationships through vector capsules and dynamic routing agreement. Utilizes Conv1-3, 784 Primary Capsules (dim 8), and 13 Disease Capsules (dim 16) with true Grad-CAM++ higher-order gradients.

GRAPH NEURAL NET

Graph Attention Network (GAT)

Converts convolutional feature representations into an image-region graph (49 spatial nodes) with 8-neighbor spatial adjacency. Uses multi-head graph attention to model dependencies across thoracic anatomical sectors.
